# FWK009 — Test Script Version Verification at Startup

## Statement

Every test script shall verify compatible versions of both config and function at startup; exit with a clear error if mismatched.

## Rationale

See statement.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
