# NET012 — SSH Lifeline NIC Protection

## Statement

Before moving any NIC into a namespace, net_test.sh shall identify the NIC currently used by the default route (SSH lifeline) and emit a WARN if that NIC is in the test set. With _net_test_strict_lifeline=1 (config default), the test shall refuse to start if the lifeline NIC would be consumed.

## Rationale

Safety net for NET011 — even if operator forgets to exclude, framework refuses to break SSH.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
