# DOC001 — Scope of "Framework" Term

## Statement

"Framework" in this document refers to the entire test automation system, including: the shell/PowerShell library layer (config, function), the individual test scripts (disk_test, net_test, dev_detect), and the orchestration layer that deploys and runs them on DUTs.

## Rationale

Scope definition — establishes what is and is not part of the framework.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.

Not formally verified; this is a definitional convention.
