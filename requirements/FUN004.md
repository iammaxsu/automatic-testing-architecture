# FUN004 — Idempotent Tool Installation

## Statement

Tool installation functions (fio_install, iperf3_install, etc.) shall be idempotent: calling them when the tool is already installed shall be a no-op.

## Rationale

Prevents reinstall on every run.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
