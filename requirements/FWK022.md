# FWK022 — Result Packaging and Retrieval

## Statement

Test results from each DUT shall be packaged (tar.gz) and pulled back to the controller after each run, organised by <dut_hostname>/<run_timestamp>/.

## Rationale

Standardises log retrieval format for downstream analysis and report generation.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
