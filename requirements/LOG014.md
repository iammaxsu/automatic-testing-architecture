# LOG014 — Log Entry Timestamp and Level Prefix

## Statement

Each log entry shall be prefixed with an ISO-8601 timestamp and log level (INFO / WARN / ERROR / DEBUG). Log levels shall be drawn from: DEBUG, INFO, WARN, ERROR, FATAL. Example: [2025-10-01 09:46:30] [INFO] Starting disk test loop 2/3

## Rationale

Current log() only adds timestamp; adding log level is industry standard and enables automated log parsing.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
