# LOG019 — result.json Schema Version

## Statement

The result.json shall declare a schema version field _result_schema_version following the same ##.##.## convention as FWK006/FWK007. Breaking changes shall increment the major version.

## Rationale

Schema versioning enables breaking-change detection by downstream consumers.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.

Code Review
