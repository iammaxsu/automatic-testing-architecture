# CMP004 — Required Tool Declaration and Auto-Install

## Statement

Tests shall declare their required external tools as a list (e.g. _required_tools=(fio lsblk findmnt blkid)). On startup, missing tools shall trigger auto-install via the framework's installer; if install fails, test shall exit with a clear error naming the missing tool.

## Rationale

Replaces ad-hoc `command -v X || X_install` patterns scattered through scripts. Centralises tool-readiness checks at startup.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
