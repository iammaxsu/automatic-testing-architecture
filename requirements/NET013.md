# NET013 — iperf3 Log Filename Convention

## Statement

Each individual iperf3 invocation shall produce a separate log file. iperf3 log filenames shall follow: iPerf3_<ev>_n_<od>_<n>of<m>_<type>_spd<speed>_<timestamp>.log. Example: iPerf3_enp46s0_n_enp48s0_1of1_TCP_spd1000_20260508T090638.log

## Rationale

iperf3 equivalent of LOG012 (fio log naming). Pairs with NET006. The spd<speed> field enables per-speed log identification when multiple speeds are tested on the same pair.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
