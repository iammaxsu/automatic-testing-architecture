# SET003 — config Contains No Executable Logic

## Statement

config.sh/.ps1/.py shall not contain executable logic; it shall only declare variables and define setup_session().

## Rationale

Prevents side-effects when config is sourced multiple times.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
