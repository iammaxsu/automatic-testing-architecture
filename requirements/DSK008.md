# DSK008 — Invalid Block Device Filtering

## Statement

The script shall filter out invalid block devices before adding them to the SAFE target list. Devices to exclude automatically (without requiring operator confirmation): (a) any block device with reported capacity of 0 bytes — typically empty SD/MMC card slots or unpopulated BMC virtual media; (b) removable optical drives (type=rom, e.g. sr0-sr3), including BMC virtual CD-ROM; (c) loop devices (type=loop). The exclusion list shall be logged with the reason for each excluded device.

## Rationale

In systems with BMC (e.g. AST2500, IPMI-equipped servers), the BMC exposes 4 virtual mass-storage devices and 4 virtual CD-ROMs by default. Without this filter, disk_test.sh adds them to SAFE targets and either fails immediately on fio or wastes the operator's confirmation step. Implementation reference: lsblk -dnb -o NAME,SIZE,TYPE; treat SIZE=0 as invalid, exclude TYPE=rom and TYPE=loop.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
