# FWK002 — Private Variable Naming

## Statement

Private variables shall be prefixed with underscore: _var_name (e.g. _session_id).

## Rationale

See statement.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
