# NET008 — Verdict Assignment per Test Item

## Statement

A verdict (PASS / FAIL / UNKNOWN) shall be assigned to each test item and recorded in the summary log.

## Rationale

Current summary only records measured rates; no explicit pass/fail threshold is defined. UNKNOWN is a valid intermediate verdict until NET009 thresholds are defined.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
