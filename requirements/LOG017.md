# LOG017 — Three-Artefact Output Model

## Statement

Each test run shall produce a human-readable .log file in the session directory. When result.json is also produced (per LOG015), it shall be a sibling file in the same directory; when an HTML report is also produced, it shall be a derivative of result.json (see LOG018). HTML report filename shall follow: <test>_report_<timestamp>.html. Example: net_report_20260508T090638.html

## Rationale

Defines the three-artefact model (.log mandatory, .json/.html conditional).

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
