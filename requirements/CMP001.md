# CMP001 — Primary Supported OS Declaration

## Statement

The framework shall declare a list of primary supported OS for which all Must-priority requirements are guaranteed to pass automated verification. Initial list: Ubuntu 24.04 LTS, Ubuntu 26.04 LTS.

## Rationale

Without explicit primary support, "works on my machine" creates incompatibility surprises across DUTs.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.

## Verification

Code Review
