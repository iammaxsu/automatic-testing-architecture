# FWK023 — Parallel Multi-DUT Execution

## Statement

The framework shall support running the same test against multiple DUTs in parallel without result collision.

## Rationale

Required when test bench scales to >1 DUT.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
