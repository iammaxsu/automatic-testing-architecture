# FUN006 — Exactly-Once Counter Semantics

## Statement

The counter_init / counter_tick / counter_remaining functions shall guarantee exactly-once execution semantics across power cycles for a given session.

## Rationale

Core to FWK013 (resume after power cycle).

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
