# DET009 — Golden Reference Comparison

## Statement

On first run, a golden reference file shall be created from the detection output. On subsequent runs, the output shall be diffed against the golden file; any deviation shall be flagged as a FAIL.

## Rationale

See statement.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.

Automated Test
