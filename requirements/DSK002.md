# DSK002 — OS Partition Exclusion from Destructive Tests

## Statement

Any disk that contains, or is a parent of, the OS partition, swap, or any mounted filesystem listed in /etc/fstab shall be excluded from destructive testing.

## Rationale

See statement.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
