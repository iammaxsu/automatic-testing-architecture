# DSK006 — Disk Test Summary Table Format

## Statement

The disk_test summary shall present results in a table with columns: Device, Pattern, Direction, Avg MiB/s, Avg MB/s, Min MiB/s, Max MiB/s, Verdict.

## Rationale

Current summary omits Min/Max and Verdict — needed for SPC and regression detection.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
