# FWK027 — No Silent State Mutation in Helper Functions

## Statement

Helper functions in function.sh shall not silently mutate framework-wide state variables (e.g. _session_id, _session_t0) outside their declared concern. State cleanup that affects multiple subsystems shall be in dedicated functions (e.g. clear_session_id) that callers invoke explicitly.

## Rationale

Codifies the lesson from BUG0019. counter_tick was modifying session state as a side effect; emit_result_json had no way to know. Explicit > implicit.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
