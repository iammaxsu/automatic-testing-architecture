# NET001 — Enumerate enp and eno Interfaces

## Statement

The script shall enumerate all enp* and eno* network interfaces present in the system. Subject to NET011/NET012 safeguards — NICs explicitly excluded by config or identified as the SSH lifeline shall not be enumerated.

## Rationale

See statement.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
