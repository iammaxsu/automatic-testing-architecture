# NET010 — Parallel NIC Pair Testing

## Statement

Due to the pair of network is independent, they are able to run tests in parallel.

## Rationale

Reduces total test time when many NIC pairs are present. Requires resource isolation between pairs (separate netns / iperf3 ports).

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
