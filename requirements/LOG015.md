# LOG015 — Machine-Readable result.json

## Statement

A machine-readable result file (<test>_<session>.result.json) shall be produced alongside the human-readable log for every test.

## Rationale

Enables CI/CD integration and trend analysis across many runs.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
