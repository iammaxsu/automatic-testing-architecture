# NET011 — NIC Include/Exclude Lists

## Statement

net_test.sh shall allow operators to exclude specific NICs from testing so that the SSH lifeline NIC is never consumed by network namespace operations.

Current implementation: a `--skip <nic>[,<nic>…]` CLI flag (repeatable) causes listed NICs to be excluded from namespace assignment. Excluded NICs appear as SKIPPED rows in the summary log and result.json.

Future enhancement: config-based include/exclude lists (_net_test_include_pairs / _net_test_exclude_pairs) for persistent per-DUT policy without CLI flags.

## Rationale

Resolves BUG0015. Without this, operators cannot prevent net_test from consuming the SSH lifeline NIC on remotely-managed DUTs.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
