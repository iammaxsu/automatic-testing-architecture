# SLP004 — Post-Wake Service Verification

## Statement

After each wake, the script shall verify that all previously active services and interfaces are still operational before marking the cycle as PASS.

## Rationale

Without post-wake verification, a hang that happens to reboot looks like a pass.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
