# FWK005 — Semantic Version Strings

## Statement

All scripts shall carry a semantic version string in the format ##.##.## (e.g. 00.01.02).

## Rationale

See statement.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
