# FWK018 — Detached Execution via Session Manager

## Statement

The framework shall support detached execution so that disconnection of the controller (e.g. operator's laptop) does not abort an in-progress test run. Implementations shall use a session manager such as screen, tmux, or equivalent.

## Rationale

Discovered when controller laptop had to leave the network mid-run; screen -dmS testbench / screen -r is the reference implementation.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
