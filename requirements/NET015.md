# NET015 — Maximum Link Speed Reporting

## Statement

For each tested NIC the framework shall determine and record the maximum link
speed the NIC advertises, and for each pair the maximum speed BOTH NICs can
reach (the lesser of the two). These values shall appear in result.json and in
the rendered report alongside the per-speed results.

## Rationale

NET004 enumerates every advertised speed and tests each one, but the operator
also needs an at-a-glance "what is the fastest this NIC / this pair can do"
figure for inventory, capability auditing, and to immediately spot a NIC that
negotiated below its rating (e.g. a 2.5G NIC stuck advertising only 1G because
of a cable or partner-port limitation).

## Scope

All scripts and shared libraries in the framework.

## Implications

1. Each NIC's maximum advertised speed (Mbps) is recorded per pair.
2. The per-pair maximum (min of the two NICs) is recorded.
3. The maximum-speed figures are shown in the rendered report.
4. Non-compliance must be corrected before merge.
