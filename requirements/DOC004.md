# DOC004 — Test Verdict Vocabulary

## Statement

Test verdict values shall use one of: PASS, FAIL, UNKNOWN, ERROR, SKIPPED. Definitions: PASS (all measurements met thresholds); FAIL (at least one measurement failed threshold); UNKNOWN (test completed but no threshold defined); ERROR (test execution itself failed — script crash, tool missing, etc.); SKIPPED (precondition not met — e.g. no safe disk found).

## Rationale

Formally defines the verdict vocabulary used across all test scripts. Pairs with NET008, DSK005, LOG015, and the verdict table.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
