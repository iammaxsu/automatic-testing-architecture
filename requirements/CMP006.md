# CMP006 — Bug OS Column Scope Convention

## Statement

Each bug report's OS column records the OS version where the bug was first observed. A bug is not implicitly scoped to that OS — reproduction on other OS versions is tracked in the Comment column. When a bug is verified on multiple OS versions, all are listed.

## Rationale

Clarifies BUG List convention to prevent OS column being read as a scope limitation.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
