# LOG021 — Output File Ownership

## Statement

All output files (.log, .result.json, .html) shall be owned by the invoking user, not root, even when the script internally uses sudo. Recommended approach: chown ${SUDO_USER:-$USER} after generation.

## Rationale

Implementation: fix_log_permissions() in function.sh handles chown ${SUDO_USER:-${USER}} via trap EXIT. Resolves BUG0002. Pairs with FWK026.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
