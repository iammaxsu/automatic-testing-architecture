# DOC003 — Bug Status Vocabulary

## Statement

Bug status field shall use one of: Open, In Progress, Resolved, Closed, Invalid, Won't Fix. Definitions: Open (awaiting work); In Progress (actively being fixed); Resolved (fixer-verified, awaiting independent verification); Closed (independently verified — e.g. via end-to-end Ansible run); Invalid (not a bug); Won't Fix (acknowledged, no fix planned).

## Rationale

Aligns with industry conventions (Jira/Bugzilla style).

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.

## Verification

Not formally verified; this is a definitional convention.
