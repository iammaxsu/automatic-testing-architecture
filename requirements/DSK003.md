# DSK003 — Explicit Confirmation Before Destructive Tests

## Statement

Before executing destructive fio tests, the script shall display the list of target disks and require explicit user confirmation (or YES_I_UNDERSTAND=1 for headless mode).

## Rationale

See statement.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
