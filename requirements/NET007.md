# NET007 — Configurable iperf3 Duration

## Statement

The iperf3 test duration shall be configurable (default: 60 s); a configurable omit period shall exclude the ramp-up phase (default: 3 s).

## Rationale

Currently hardcoded in net_test.sh; must be a config parameter.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
