# LOG018 — HTML Report Generated from result.json

## Statement

The HTML report, when produced, shall be generated from result.json (not by re-parsing the .log file). Bidirectional dependency between .log and result.json is prohibited.

## Rationale

Prevents BUG0001-class issues where HTML and log data diverge.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.

## Verification

Code Review
