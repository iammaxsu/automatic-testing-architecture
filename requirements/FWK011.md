# FWK011 — Strict Error Handling

## Statement

Scripts shall enable strict error handling (bash: set -Eeuo pipefail; PowerShell: Set-StrictMode -Version Latest; Python: explicit exception handling).

## Rationale

Note: strict mode (set -Eeuo pipefail) can mask root-cause when a sub-command fails silently in a pipeline (see BUG0011 — Closed; fix: Ansible pre-installs all required tools). Phase 3: _safe wrappers per CMP005.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
