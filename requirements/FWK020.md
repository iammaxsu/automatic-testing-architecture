# FWK020 — DUT-Side Test Completion Detection

## Statement

The framework shall correctly detect DUT-side test completion across power cycles and reboots, using a reliable signal (file marker, exit code, or systemd unit state).

## Rationale

Pairs with FWK013 (DUT-side resume); FWK020 covers the controller-side completion-detection counterpart.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
