# LOG012 — fio Log Filename Convention

## Statement

fio log filenames shall follow: <dev>_<rw>_<bs>_Q<iodepth>T<numjobs>_<n>_of_<m>_<timestamp>.log Example: sda_rnd_read_4K_Q32T1_3_of_10_20251001111045.log

## Rationale

See statement.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
