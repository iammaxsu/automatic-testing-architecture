# CMP003 — Distribution-Aware Package Installation

## Statement

All package installation helpers (__pkg_install, *_install) shall use distribution detection (__is_debian_like / __is_redhat_like) to map abstract tool names to concrete package names. Tool name mapping shall live in a single table in function.sh.

## Rationale

Already partially implemented in function.sh; this requirement formalises the pattern.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.

Code Review
