# FWK026 — Output File Ownership Restoration

## Statement

Test scripts running as root shall restore output file ownership to the original invoking user (SUDO_USER) before exit, including on error/interrupted paths via trap EXIT.

## Rationale

Already implemented in function.sh::fix_log_permissions. Pairs with LOG021. Resolves BUG0002.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
