# FWK021 — Flat Deployment Directory on DUT

## Statement

All test scripts and shared libraries (config.sh / function.sh / *.sh) shall be deployed to a single flat directory on the DUT, shared across all test types.

## Rationale

Reflects FWK004 — config / function are a shared API layer; per-test subdirectories would require duplicating them.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
