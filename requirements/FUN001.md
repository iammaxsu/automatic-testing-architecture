# FUN001 — Auto-Detect and Install iperf3

## Statement

The framework shall auto-detect whether iperf3 is installed; if absent, install it automatically, then proceed.

## Rationale

Subject to CMP003 / CMP004 — install helpers use distribution-detected package names.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
