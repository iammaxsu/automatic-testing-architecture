# LOG008 — Log Filename Order

## Statement

Log filename order shall be: <test_name>_<n>_of_<m>_<timestamp>_<result>.log Example: net_test_2_of_3_20251001094630_Pass.log

## Rationale

See statement.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
