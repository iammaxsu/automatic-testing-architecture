# NET006 — iperf3 Throughput in Four Combinations

## Statement

Throughput shall be measured with iperf3 in four combinations per speed: TCP forward, TCP reverse, UDP forward, UDP reverse.

## Rationale

See statement.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
