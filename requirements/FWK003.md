# FWK003 — Private Function Naming

## Statement

Private/internal functions shall be prefixed with underscore: _func_name() (e.g. _ns_create()).

## Rationale

See statement.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
