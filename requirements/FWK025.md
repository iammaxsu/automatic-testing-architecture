# FWK025 — Script Self-Elevation to Root

## Statement

Test scripts that require root for hardware access shall self-elevate at script start using exec sudo -E "$0" "$@" if not already root. Operators and orchestrators (Ansible, etc.) shall invoke them as a regular user; the script handles privilege elevation internally.

## Rationale

Implements the "sudo wrapper" / privilege boundary pattern. Keeps the orchestrator unprivileged while giving the test full hardware access. Verified on dev_detect.sh 2026-05-05.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
