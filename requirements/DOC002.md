# DOC002 — Requirement ID Prefix Convention

## Statement

Requirements prefixed FWK apply to the framework as a whole; later prefixes (LOG, NET, DSK, etc.) scope to specific concerns.

## Rationale

Naming convention — allows quick identification of a requirement's domain from its ID alone.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.

## Verification

Not formally verified; this is a definitional convention.
