# CMP005 — Graceful Handling of Unavailable Tools

## Statement

When a tool is unavailable on the running OS (e.g. no apt/dnf, or package not in any repo), the test shall log a WARN-level message and either skip the affected check or return a clearly-labelled "UNSUPPORTED" verdict. It shall not crash.

## Rationale

Prevents the BUG0011-class silent abort caused by missing tools + strict mode.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
