# FWK014 — 4-Bit Sleep State Encoding

## Statement

A 4-bit field shall encode test mode and sleep state: bit3=in-testing; bits[2:0]=sleep state (011=S3, 100=S4, 101=S5). Example: 1101=S5 in-progress.

## Rationale

Resolved: bit encoding {011=S3, 100=S4, 101=S5}; S1/S2 not supported.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
