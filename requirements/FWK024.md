# FWK024 — Non-Interactive Flags via Environment Variables

## Statement

Non-interactive flags (YES_I_UNDERSTAND=1, DISABLE_LOOPS_PROMPT=1, _bLoops) shall be passed to test scripts via environment variables, not stdin.

## Rationale

Pairs with FWK016 (headless execution).

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
