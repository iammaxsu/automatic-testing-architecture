# SET004 — Environment Variable Overrides for Config Defaults

## Statement

All default parameter values shall be overridable via environment variables before sourcing config (e.g. _fio_size=${_fio_size:-1g}).

## Rationale

Required for flexible CI/CD parameterisation.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
