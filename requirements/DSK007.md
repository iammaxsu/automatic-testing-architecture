# DSK007 — USB Storage fio Profile

## Statement

USB storage devices shall be tested with a separate, reduced fio profile appropriate for USB throughput limits.

## Rationale

Running NVMe-profile fio on a USB 2.0 drive will always fail; need differentiated profiles.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
