# LOG005 — Log Filename Includes ISO 8601 Timestamp

## Statement

Each log filename shall include a local time of the DUT in ISO 8601 basic format (YYYYMMDDTHHmmss). The T separator is mandatory to distinguish date from time across locales.

## Rationale

Resolved: use local time of the DUT; print 'Timezone: ...' line in log header.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
