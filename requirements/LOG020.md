# LOG020 — Minimum result.json Fields

## Statement

The result.json shall include at minimum these fields: test_name, session_id, host, start (ISO-8601), end (ISO-8601), elapsed_seconds, elapsed_human, loops {target, completed}, verdict, and a per-test details section.

## Rationale

Conditional on LOG015: required when result.json is produced.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
