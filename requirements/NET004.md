# NET004 — Test at All Advertised Link Speeds

## Statement

For each interface, the script shall enumerate every link speed the interface
advertises as supported and process each speed in turn:

1. Verify whether a link can be established at that speed (NET014).
2. For every speed that is connectable, run IPv4 and IPv6 connectivity (NET005).
3. For every speed that is connectable, measure TCP and UDP throughput (NET006).

No advertised speed shall be silently skipped: every advertised speed appears in
the result with at least its link verdict, whether or not it proved connectable.

## Rationale

The advertised speed set is the basis for the whole per-interface test matrix.
Driving every advertised speed — and recording the outcome of each — is what
lets the report state, per interface, exactly which speeds work end-to-end and
which fail, and at which stage (link, connectivity, or throughput) they fail.

## Scope

All scripts and shared libraries in the framework.

## Implications

1. The set of speeds tested is derived from what the interface advertises, not a
   fixed list.
2. Each advertised speed contributes at least one reported row (its link
   verdict from NET014).
3. Connectivity (NET005) and throughput (NET006) stages run only for speeds that
   are connectable; non-connectable speeds are reported as such.
4. Non-compliance must be corrected before merge.
