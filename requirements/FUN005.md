# FUN005 — Shared log() Interface

## Statement

The framework shall expose a consistent log(level, message) interface usable by all test scripts without re-defining it locally.

## Rationale

Current code has log() in function.sh hardcoded to $_disklog, breaking net_test.sh — this requirement formalises the fix.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
