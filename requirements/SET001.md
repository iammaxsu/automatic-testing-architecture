# SET001 — Tunable Parameters in config Only

## Statement

All tunable parameters (paths, timeouts, loop counts, fio sizes, sleep durations, etc.) shall be declared exclusively in config.sh/.ps1/.py.

## Rationale

See statement.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
