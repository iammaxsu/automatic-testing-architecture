# FWK019 — Status Inspectable Without Original Session

## Statement

Test status shall be inspectable without holding the original controller session, e.g. via a status file on the DUT or a re-readable remote log.

## Rationale

Backstop for FWK018 — even if session reattach fails, status remains observable.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
