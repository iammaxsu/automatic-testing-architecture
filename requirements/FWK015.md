# FWK015 — Loop Count Argument

## Statement

Each test script shall accept a positional integer argument specifying the number of loops to execute (default: 1).

## Rationale

Needed to support the counter_init / parse_common_cli pattern already in code.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
