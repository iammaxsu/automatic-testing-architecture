# LOG022 — ISO 8601 Timestamp Consistency

## Statement

All timestamps embedded in filenames, directory names, and JSON time fields shall use ISO 8601 format. Filenames and directory names use basic format (YYYYMMDDTHHmmss); JSON time fields use extended format with timezone (YYYY-MM-DDTHH:MM:SS±HH:MM).

## Rationale

Codifies the 2026-05-07 decision after BUG0019. ISO 8601 ensures unambiguous timestamp parsing across tools, locales, and shells. The 14-digit YYYYMMDDHHmmss format used previously was visually ambiguous.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
