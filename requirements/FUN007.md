# FUN007 — Windows PowerShell Shared Function Library

## Statement

All generic PowerShell utilities used by Windows test and setup scripts shall be consolidated in `src/windows/function.ps1`. The file shall:

1. Export a version variable `$_function_ps1_api` (format `MM.mm.pp`, zero-padded per segment) as the first executable statement.
2. Provide four groups of functions:
   - **Console helpers**: `Write-Step`, `Write-OK`, `Write-Skip`, `Write-Warn` — coloured output for structured script progress.
   - **Path resolution**: `Resolve-FirstExisting` — returns the first path in a list that exists on disk.
   - **PnP / hardware query helpers**: `Get-PnpProp`, `Get-ParentInstanceId`, `Ascend-ToPci`, `Parse-PcieGen`, `Approx-PcieGBsPerDir`, `Get-PcieLinkInfo`, `Get-UsbVersionHint`, `TryGet-SataLinkRate`, `Convert-LinkSpeedToGb`.
   - **Test result logging** (requires caller to define `$_log_path`, `$_counter_file`, `$_summary_file`): `Get-Date2`, `Get-NextCount`, `Ensure-Golden`, `Write-CombinedPerRunLog`, `Append-CombinedSummary`.

Every Windows script that uses these functions shall dot-source `function.ps1` using a path relative to its own location and verify API version compatibility before proceeding:

```powershell
$_fn = Join-Path (Split-Path -Parent $MyInvocation.MyCommand.Definition) 'function.ps1'
. $_fn
if ($script:_function_ps1_api -lt $_requires_function_ps1_api) { throw "..." }
```

Each calling script shall also declare its own version with `$_script_ver = 'MM.mm.pp'`.

## Rationale

Mirrors the role of `function.sh` / `function.py` in the bash and Python layers: a single shared library prevents code duplication across `setup_dut.ps1`, `dev_detect1.ps1`, and future Windows scripts, and the API version gate catches incompatibilities early.

## Scope

`src/windows/function.ps1` and all scripts that dot-source it.

## Implications

- Adding a new function to `function.ps1` is backward-compatible; callers' `$_requires_function_ps1_api` need not change.
- Changing the signature of an existing function is a breaking change; bump `$_function_ps1_api` and update all callers.
- Group-4 logging functions depend on caller-defined variables; the caller must set `$_log_path`, `$_counter_file`, and `$_summary_file` before invoking them.

## Verification

Code Review: confirm `$_function_ps1_api` is defined; confirm each caller dot-sources and checks version; confirm no function logic duplicated in individual scripts.
