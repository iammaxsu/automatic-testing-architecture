# NET009 — Minimum Throughput Thresholds

## Statement

net_test.sh shall enforce minimum throughput thresholds per speed tier and declare a per-pair verdict:

- TCP (forward and reverse): throughput ≥ 95% of link speed → PASS; below threshold → FAIL; iperf3 returned no data → UNKNOWN.
- UDP: threshold TBD; not yet implemented.

Thresholds shall ultimately be externalised to config; the current implementation uses a hardcoded 95% multiplier inside net_test.sh.

## Rationale

Without thresholds, the test can never automatically fail on degraded hardware.

## Scope

All scripts and shared libraries in the framework.

## Implications

- Non-compliance must be corrected before merge.
